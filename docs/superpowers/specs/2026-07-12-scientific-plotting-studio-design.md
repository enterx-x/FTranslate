# 科研绘图工作台设计规格

日期：2026-07-12
状态：待用户最终审阅
目标版本：下一功能版本（具体版本号在实施计划中确定）

## 1. 背景与第一性原理

科研人员经常需要把 CSV、Excel、实验表格或临时复制的数据变成论文图。当前工作流通常要求研究者手写绘图代码、反复调整样式、单独计算统计量，再手工保存代码、数据和图片。这会产生四个核心问题：

1. 绘图门槛高，重复代码多；
2. 预览图、最终图、统计结果和源代码容易不一致；
3. 图像缺少数据来源、处理步骤、统计检验和运行环境证据；
4. Python、R、MATLAB 和 JavaScript 各有优势，但用户难以在一个项目中安全切换。

不可压缩的核心约束是：

- 图必须由用户选择的真实绘图语言或引擎生成，不能用 ECharts 假装 Python、R 或 MATLAB；
- 不使用 AI 自动绘图，不上传数据，不让模型猜测字段、统计检验或图表结论；
- 原始数据、转换过程、统计检验、样式配置、语言版本和导出结果必须可追溯；
- 用户不需要手写代码即可完成常见绘图，但必须能查看、复制和导出生成代码；
- 应用只运行由自身模板生成且通过白名单校验的脚本，不在绘图工作台内执行任意用户代码；
- MATLAB 是商用软件，只检测已有安装、许可证和工具箱，不由 FTranslate 下载或安装。

最小可验证闭环是：

> 导入数据 -> 检查类型和质量 -> 显式配置转换与统计 -> 选择图形和绘图语言 -> 由所选语言真实渲染预览 -> 导出图片、脚本和可复现项目。

该能力服务 FTranslate 的本地化 AI 科创研发闭环：实验矩阵或研究表格中的结果可以进入绘图项目，图表又可以关联回研究项目、论文和实验记录，成为可验证的研发证据，而不是孤立图片。

## 2. 目标与非目标

### 2.1 目标

- 支持 CSV、TSV、Excel、当前 Univer 科研表格区域和粘贴表格数据。
- 提供基础图、统计图、高级科研图、多面板排版和出版级导出。
- 首版支持 JavaScript/ECharts、Python、R 和 MATLAB 四种渲染选择。
- Python 与 R 支持检测系统环境或配置 FTranslate 私有环境；MATLAB 仅检测。
- 预览、最终导出和生成脚本都使用当前选择的语言。
- 提供明确的数据清洗、统计设计、显著性标注和结果溯源。
- 绘图项目既可独立存在，也可关联研究项目、论文、实验矩阵行和数据源。
- 在 1366px、1440px 和 1920px 桌面宽度下保持高密度、可扫描、无遮挡的专业工作台 UI。

### 2.2 非目标

- 不做 AI 选图、AI 数据解释、AI 自动统计或自然语言生成图表。
- 不做通用代码 IDE、Notebook 或任意脚本执行器。
- 不在首版支持 Julia、Octave、SAS、SPSS 或 Origin 自动化。
- 不下载、破解或静默安装 MATLAB，也不绕过许可证检查。
- 不保证一个绘图项目在四种语言下像素级一致；保证语义、数据和统计设置一致，并如实记录渲染差异。
- 不用论文预设替代期刊投稿指南。预设只是可编辑的起始配置，导出前仍需用户核对目标期刊的最新规范。

## 3. 整体信息架构

新增一级工作区入口“绘图”，进入科研绘图工作台。工作台采用用户确认的三栏 A 布局：

1. 左栏“数据与字段”：数据源、数据健康、字段搜索、类型修正、转换流水线；
2. 中栏“绘图画布”：图形工具栏、真实预览、缩放、适应画布、渲染状态和结果摘要；
3. 右栏“Inspector”：图层、统计、样式、注释和导出设置。

顶部工具栏显示当前绘图项目、绘图语言、运行状态、“管理环境”、“查看脚本”和“导出结果”。运行环境配置不常驻：

- 主界面只保留紧凑的语言选择器、当前状态和“管理环境”按钮；
- 点击按钮才打开独立运行环境弹窗；
- 只有用户选择了缺失的 Python/R 环境时，首次运行才自动弹出配置；
- 关闭弹窗后空间完全归还绘图工作区；
- MATLAB 缺失时只显示检测与说明，不显示安装按钮。

在 1280px 以下，右侧 Inspector 变成可展开抽屉；左栏可以收窄但不能覆盖画布。隐藏任何侧栏后都必须释放真实布局宽度，不允许保留空白列。

## 4. 数据导入与数据生命周期

### 4.1 导入入口

左栏常驻一个明确的“＋ 导入数据”主按钮。点击后打开按需弹窗，提供三种来源：

1. 本地文件：CSV、TSV、XLSX；Excel 文件需要选择工作表；
2. 当前科研表格：导入整个 Univer 工作表或当前选中区域；
3. 粘贴表格：接收从 Excel、Origin、MATLAB 等复制的制表符或分隔符数据。

导入弹窗必须先显示解析预览，至少包括：文件名或来源、工作表、编码、分隔符、表头行、前若干行数据、有效行数、字段数、缺失值、重复行和初步字段类型。用户确认后才创建数据快照。

### 4.2 数据快照与转换

每次导入生成不可变的原始数据快照。后续所有操作形成有序、可回溯的转换流水线，不覆盖原始文件或原始快照。首版转换包括：

- 字段重命名和显式类型修正；
- 缺失值保留、删除或指定策略处理；
- 行过滤、排序、分组和聚合；
- 宽表/长表转换；
- 单位换算和基础公式派生字段；
- 分类顺序和标签映射；
- 多数据表连接或追加（在兼容字段检查后执行）。

每一步记录参数、输入快照、输出摘要、执行时间和错误。删除或调整步骤后从最近可复用缓存重算。任何降采样、缺失值删除或异常值排除都不能静默发生。

### 4.3 大数据预览

- 导入、转换、统计和外部语言渲染均在后台任务中执行，不阻塞 renderer UI。
- 大数据可以先显示明确标注的抽样预览；统计分析和最终导出默认使用完整数据。
- 如果最终渲染也需要降采样，必须由用户显式启用并写入转换记录和图注来源信息。
- 结果缓存键由数据快照哈希、转换配置、统计配置、绘图配置、语言和运行环境版本共同组成。

## 5. `ScientificPlotSpec` 中间表示

应用以版本化、与具体绘图库解耦的 `ScientificPlotSpec` 作为单一配置事实源。建议结构：

```ts
interface ScientificPlotSpec {
  schemaVersion: string;
  id: string;
  title: string;
  dataSource: DataSourceRef;
  snapshot: DataSnapshotRef;
  transforms: TransformStep[];
  analysis: AnalysisSpec[];
  chart: ChartSpec;
  encodings: EncodingSpec;
  layers: LayerSpec[];
  facets?: FacetSpec;
  axes: AxisSpec[];
  annotations: AnnotationSpec[];
  theme: ThemeSpec;
  renderer: RendererSpec;
  exports: ExportPreset[];
  provenance: ProvenanceRecord;
  links: ResearchObjectLink[];
}
```

`ScientificPlotSpec` 负责保存绘图语义，而语言编译器负责把同一语义转换为 ECharts option、Python 脚本、R 脚本或 MATLAB 脚本。切换语言时保留数据、字段映射、转换和统计设计；如果目标语言不支持某能力，界面必须指出具体不兼容项和替代方案，不得静默删除配置或回退到 ECharts。

## 6. 图形能力与兼容矩阵

首版图形家族分层提供：

### 6.1 基础与统计图

- 折线图、散点图、柱状图、面积图；
- 误差线、置信区间带、分组/堆叠、趋势线；
- 直方图、密度图、ECDF；
- 箱线图、小提琴图、雨云图、蜂群/抖动点；
- 相关矩阵、普通热图、聚类热图；
- 分面、多面板和共享图例布局。

### 6.2 高级科研图

- 等高线、二维密度、三维曲线/散点/曲面；
- Sankey、alluvial；
- 生存曲线、森林图、火山图；
- 极坐标/雷达图在明确科研场景下可用，但不作为默认推荐；
- 自定义注释层、参考线、阈值区间和实验阶段背景。

### 6.3 渲染器定位

- JavaScript/ECharts：内置、即时、交互式，适合大多数基础图和快速探索；
- Python：Matplotlib、Seaborn、Plotly、SciPy/Statsmodels，适合与 Python 实验代码衔接；
- R：ggplot2、patchwork、ComplexHeatmap 及受控高级图扩展，适合统计图和出版排版；
- MATLAB：使用用户已有 MATLAB 和已安装工具箱，适合控制、信号、仿真和既有 MATLAB 数据链。

每个图形模板必须声明渲染器能力矩阵、需要的包/工具箱、支持的导出格式和降级策略。无真实支持时禁用选项，并解释原因。

## 7. 统计分析与显著性标注

统计能力包括：

- 描述统计：均值、中位数、标准差、标准误、分位数和置信区间；
- 回归与趋势拟合；
- 独立/配对 t 检验；
- 单因素、多因素和重复测量 ANOVA（以渲染器能力和依赖为准）；
- Mann-Whitney、Wilcoxon、Kruskal-Wallis、Friedman 等非参数检验；
- Holm、Bonferroni、Benjamini-Hochberg 等多重比较校正；
- Cohen's d、Hedges' g、η²/partial η²、秩二列相关等效应量。

系统不自动猜测检验。用户必须显式选择：比较对象、独立或配对设计、重复测量标识、尾部方向、显著性水平、多重校正和效应量。若数据不满足最小结构要求，阻止执行并解释缺少的字段或分组。

`AnalysisSpec` 由当前选择语言的受控脚本执行；结果写入版本化的 `analysis-results.json`。每个显著性标注绑定具体比较、样本量、检验名、原始 p 值、校正后 p 值、效应量、置信区间、语言/包版本和时间戳。切换语言会重新计算并记录新结果，允许存在合理的浮点或算法实现差异，但必须在测试容差和来源信息中可见。

不允许像早期概念稿那样在没有真实数据和检验的情况下生成 p 值或显著性括号。

## 8. 真实语言渲染

### 8.1 JavaScript/ECharts

ECharts 作为应用内置渲染器，在 renderer 的受控组件中真实生成 SVG 或 Canvas。它不是其他语言的预览替身。

### 8.2 Python 与 R

主进程为每次渲染建立隔离工作目录，写入经过 schema 验证的输入数据、`ScientificPlotSpec` 和由受控模板生成的脚本，通过子进程运行。脚本输出：

- 预览 SVG/PNG 或受控 HTML；
- 最终图片；
- `analysis-results.json`；
- `render-manifest.json`；
- 标准输出和错误日志。

应用只允许执行自身模板生成的脚本和白名单包。用户可以查看、复制、另存或在外部工具中修改脚本，但修改后的任意脚本不能直接返回应用内执行。

### 8.3 MATLAB

通过 Windows 注册表、`where.exe`/显式路径和 `matlab.exe` 能力探测已有 MATLAB，记录版本、许可证可用性和工具箱。渲染使用 `matlab -batch` 调用受控生成脚本。由于启动成本高，MATLAB 默认采用手动“重新渲染”，而不是每个控件变化都自动执行。

### 8.4 状态与失败处理

每个渲染任务具有 queued、running、succeeded、failed、cancelled、timed-out 状态。任务支持进度、取消、超时和重试。失败时：

- 保留最后一次成功预览，但覆盖明显的“预览已过期”标记；
- 禁止把旧预览当作当前配置直接导出；
- 显示失败阶段、退出码、经过脱敏的日志摘要和修复入口；
- 不自动切换语言，不隐藏缺失依赖，不以空白图表示成功。

## 9. 运行环境管理

### 9.1 安装期选择

Windows 安装器增加可选绘图环境意向页：

- JavaScript/ECharts 始终内置；
- Python 私有环境：可选；
- R 私有环境：可选；
- MATLAB：仅选择“首次启动时检测”，不安装。

安装器只记录选择，不在安装 UI 中执行大体积下载。首次启动后，运行环境管理器根据选择检测已有环境；缺失时再显示下载体积、来源、目标目录、进度、取消、重试和路径选择。

### 9.2 检测与私有环境

- 优先检测用户显式选择的环境，其次检测系统环境；
- Python/R 可以配置 FTranslate 私有环境，默认放在用户可写的独立目录，不污染系统 Python/R；
- 下载只使用明确版本和可信官方来源，安装前校验 SHA256；
- Python 包和 R 包使用固定依赖清单，升级需要显式操作；
- MATLAB 仅保存路径和能力检测结果，不复制程序文件或许可证信息。

运行环境弹窗显示：语言、版本、路径、核心包/工具箱、健康状态、上次检测时间、修复/重检和卸载私有环境入口。卸载只允许删除 FTranslate 自己创建且路径校验通过的私有环境，绝不删除系统环境。

## 10. 主题与论文预设

提供以下可编辑起始预设：

- 通用科研图；
- Nature/Science 风格；
- IEEE；
- Elsevier；
- 中文学位论文；
- 用户实验室模板。

预设定义画布尺寸、字体、字号、线宽、点形、配色、图例、网格、面板间距和导出分辨率。预设名称只表示设计起点，不声称符合所有期刊、子刊或会议的最新投稿要求。用户修改后可保存实验室模板并记录继承来源。

## 11. 项目存储、关联与可复现包

### 11.1 本地项目存储

轻量索引和最近项目元数据存储在应用状态中；大数据和渲染产物放在 Electron `userData` 下的专用 plot projects 目录。每个项目至少包含：

```text
plot-project/
  manifest.json
  plot-spec.json
  data/raw/<snapshot>
  data/derived/<artifact>
  analysis/analysis-results.json
  scripts/<generated-script>
  renders/<preview-and-exports>
  logs/<render-log>
  themes/<custom-theme>
```

绘图项目可以独立存在，也可以通过稳定 ID 关联研究项目、论文、实验矩阵行和 Univer 数据区域。删除关联对象不自动删除绘图项目；只显示失效关联并提供重新绑定。

### 11.2 `.fplot` 可复现包

`.fplot` 是版本化 ZIP 容器，包含 manifest、PlotSpec、转换配置、统计配置、生成脚本、依赖/工具箱清单、主题、统计报告和选定导出结果。它不包含 Python、R、MATLAB 程序本体。

为避免泄露，分享包默认不包含原始数据和处理后数据。导出时分别提供明确复选框和数据摘要，用户主动确认后才加入。导入 `.fplot` 时先显示文件清单、schema 版本、数据是否包含和运行环境需求，再创建新的本地项目，不覆盖同 ID 的现有项目。

## 12. 导出设计

导出弹窗分为：图片、论文素材、可复现包三类。

- 图片：PNG、SVG、PDF、TIFF；提供尺寸、DPI、透明背景、字体嵌入和裁边设置；
- 论文素材：图片、图注草稿、统计摘要、数据/处理来源说明和当前语言源代码；
- 可复现包：`.fplot`、脚本、依赖清单、统计结果，以及用户显式选择的数据快照。

所有导出由当前所选语言完成。格式不受目标渲染器支持时禁用并解释，不通过其他语言代替。导出 manifest 记录文件哈希、生成时间、PlotSpec 版本、语言/库版本、数据快照哈希和统计结果哈希。

## 13. 安全、隐私与异常边界

- 数据默认只在本机处理，不上传任何云端服务。
- Excel 导入只读取单元格数据和必要格式信息，不执行宏、外部链接或嵌入对象。
- IPC 输入使用 schema 验证并限制路径、文件类型、文件大小和数组长度。
- 子进程使用固定 executable、参数数组、隔离工作目录和超时，不通过 shell 拼接命令。
- 生成脚本不接受任意代码片段、任意包名、任意文件路径或网络请求。
- 输出路径必须经过规范化并验证位于允许目录内；覆盖已有文件必须显式确认。
- 文件损坏、编码错误、工作表缺失、字段类型错误、依赖缺失、许可证不可用、磁盘空间不足和进程崩溃都要返回结构化错误。
- 日志不得包含数据正文、密钥或不必要的私人路径；诊断包由用户预览后主动导出。

## 14. 性能目标

以下是开发和验收预算，不作为跨所有硬件的绝对承诺：

- 打开导入弹窗和切换 Inspector tab 不产生可感知主线程阻塞；
- 100,000 行规则表格优先流式解析并尽快给出首屏预览；
- ECharts 配置变化采用防抖和增量更新；
- Python/R 连续参数变化只保留最新待执行任务，已开始任务可取消；
- MATLAB 默认手动重新渲染，避免反复冷启动；
- 重复的相同 PlotSpec 命中缓存，不再次启动外部进程；
- 大文件、复杂统计和高分辨率导出始终显示进度，允许取消且不留下伪成功产物。

实施计划需要用当前开发机基准数据确定具体行数、耗时和内存门槛，测试不能只依赖时间断言。

## 15. 测试与验收

### 15.1 纯逻辑测试

- PlotSpec schema、版本迁移和非法配置；
- CSV/TSV 编码、分隔符、引号、空行、长字段和类型推断；
- Excel 多工作表、空工作表、合并单元格和公式值读取；
- Univer 区域和粘贴表格转换；
- 转换流水线、回滚、缓存键和快照不可变性；
- 固定数据集下的均值、CI、回归、t 检验、ANOVA、非参数检验、多重校正和效应量；
- 导出 manifest、文件哈希和 `.fplot` schema。

### 15.2 渲染器测试

## 16. 实施分期

用户要求完整交付，因此分期只用于降低实施风险，不代表只交付部分功能。下一实施计划应按依赖顺序完成全部范围：

1. PlotSpec、项目存储、导入和数据转换基础；
2. 三栏绘图工作台、ECharts 真实预览和基础图；
3. Python/R 运行环境与真实渲染；
4. MATLAB 检测与真实渲染；
5. 统计、显著性和高级图；
6. 主题、导出和 `.fplot`；
7. 全量测试、视觉对抗式审查、安装包和打包产物验证。

每一阶段都必须保持已有论文库、研究表格、PDF 阅读、arXiv 和项目空间可用；不得用破坏性迁移换取功能跑通。

## 17. 已确认的设计决策

- 不使用 AI 绘图；
- 采用三栏 A 布局；
- 数据来源包含文件、Univer 和粘贴；
- 支持完整基础/统计/高级图形范围；
- 支持 JavaScript/ECharts、Python、R、MATLAB；
- 预览必须由所选语言真实生成；
- Python/R 可检测或安装私有环境，MATLAB 只检测；
- 安装器记录可选环境意向，首次启动再配置；
- 运行环境管理使用按需弹窗，不常驻；
- 统计检验必须显式配置且结果可追溯；
- 导出图片、源代码、统计材料和可复现项目；
- 分享包默认不包含数据，需用户主动确认；
- 失败不静默回退，保留但标记旧预览；
- 所有内容完成后才视为功能交付完成。
